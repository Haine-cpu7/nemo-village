# ねもの村 v0.1

100体のねもが、なんとなく毎日暮らしている静的Webサイトです。

## 今入っているもの

- Nemo #01〜#100
- 個体ごとに固定された2つの性格
- 好きなもの・お気に入りの場所
- 8つの場所
  - パン屋
  - 図書館
  - 池
  - 森
  - 花畑
  - 温泉
  - 広場
  - 雑貨屋
- 日ごとに変わる行動
- ごきげん
- たからもの
- 最近の日記
- 番号検索
- 場所フィルター
- スマホ対応

## 重要

v0.1ではサーバーもAI APIも使っていません。

日付とNemo番号から毎日の状態を決めているため、
同じ日にサイトを開けば、誰が見ても同じ村の状態になります。

そのため、

- サーバー代なし
- AI API代なし
- PCつけっぱなし不要

でGitHub Pagesにそのまま公開できます。

## GitHub Pagesに置く

1. GitHubで新しいPublic repositoryを作る
   - 例: `nemo-village`
2. このフォルダの
   - `index.html`
   - `style.css`
   - `app.js`
   をリポジトリ直下へアップロード
3. GitHubの `Settings`
4. `Pages`
5. `Build and deployment`
6. Sourceを `Deploy from a branch`
7. Branchを `main` / `(root)` にする
8. Save

少し待つと公開URLが発行されます。
